# smalltv-live (host)

Renders the SmallTV Live screen (clock, weather, Claude usage and an animated Boston terrier) and streams it to a GeekMagic SmallTV-Ultra running the SmallTV Live firmware.

```sh
smalltv-live run                 # stream to the TV until stopped
smalltv-live preview screen.png  # render one frame
smalltv-live statusline          # Claude Code status line command that caches usage limits
```

See the [project README](https://github.com/synack1337/smalltv-live#readme) for installation and configuration.
