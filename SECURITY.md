# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub: **Security > Report a vulnerability** on this repository. Include the firmware or host version, what you found and how to reproduce it.

You can expect an acknowledgement within a week. Please don't open a public issue for a vulnerability before it is fixed.

## Supported versions

Only the latest release of the firmware and the host receives fixes.

The threat model and what each part exposes are described in [docs/security.md](docs/security.md).
